💰 Conversor de Moedas

Este é um Dashboard moderno e responsivo para conversão de moedas e acompanhamento de taxas de câmbio. O projeto foi desenvolvido com foco em experiência do usuário, oferecendo uma interface limpa e funcionalidades úteis para o dia a dia financeiro.

🚀 Funcionalidades

Conversão de Moedas: Cálculo instantâneo entre diversas moedas globais, usando o Real (BRL) como moeda-base para a conversão cruzada.

Cotações Fixas (Demonstração): As taxas de câmbio são valores fixos definidos no código, não uma cotação em tempo real de mercado. Ideal para fins de estudo e demonstração da lógica de conversão.

Sistema Multilíngue: Suporte completo para Português (BR), Inglês (US) e Espanhol (ES).

Modo Escuro (Dark Mode): Interface adaptável para maior conforto visual, com paleta de cores dedicada.

Tabela de Cotações: Visualização rápida do valor das principais moedas em relação ao Real.

Modo Privacidade: Opção para ocultar valores convertidos na tela.

Notícias do Mercado: Cards com atualizações fictícias sobre o câmbio e links externos para sites de economia reais.

Design Responsivo: Menu lateral (Sidebar) adaptado para dispositivos móveis, com menu deslizante (drawer) e overlay.

🛠️ Tecnologias Utilizadas

- React.js: Biblioteca principal para construção da interface baseada em componentes.
- JavaScript (ES6+): Lógica de conversão e manipulação de estados.
- CSS3: Estilização personalizada com variáveis (CSS custom properties), Flexbox e Media Queries para responsividade.
- FontAwesome: Ícones profissionais para navegação e interface.
- Vite: Ferramenta de build para um desenvolvimento rápido e otimizado.

🔍 Visão Geral Detalhada

- Conversor Multimoedas: Formulário interativo onde o usuário seleciona moedas de origem e destino (como BRL para USD) e calcula valores com taxas pré-definidas.
- Placar das Moedas (Tabela): Tabela comparativa mostrando quanto vale 1 unidade das principais moedas mundiais (Dólar, Euro, Libra, etc.) em relação ao Real (BRL).
- Sistema de Temas: Alternância entre Modo Claro e Modo Escuro via ícone de lua/sol no cabeçalho.
- Multilíngue: Suporte a três idiomas, alterando todos os textos da interface instantaneamente.
- Notícias do Mercado: Seção com cards sobre movimentações do câmbio e links externos para sites de economia.
- Modo Privacidade: Função nas configurações que oculta os valores convertidos (exibindo "••••••") para maior discrição.

💰 Multi-Currency Converter

This is a modern and responsive Dashboard for currency conversion and exchange rate monitoring. The project was developed with a focus on user experience, offering a clean interface and useful features for daily financial activities.

🚀 Features

- Currency Conversion: Instant calculation between various global currencies, using the Brazilian Real (BRL) as the base currency for cross-conversion.
- Fixed Rates (Demo): Exchange rates are fixed values defined in the code, not real-time market data. Ideal for study and demonstration purposes.
- Multilingual System: Full support for Portuguese (BR), English (US), and Spanish (ES).
- Dark Mode: Adaptive interface for better visual comfort, with a dedicated color palette.
- Exchange Rate Table: Quick view of the value of major currencies relative to the Brazilian Real (BRL).
- Privacy Mode: An option to hide converted values on the screen.
- Market News: Cards with fictional exchange rate updates and external links to real economics sites.
- Responsive Design: Side menu (Sidebar) adapted for mobile devices, with a sliding drawer and overlay.

🛠️ Technologies Used

- React.js: Main library for building the component-based interface.
- JavaScript (ES6+): Conversion logic and state management.
- CSS3: Custom styling with CSS variables, Flexbox and Media Queries for responsiveness.
- FontAwesome: Professional icons for navigation and UI.
- Vite: Build tool for fast and optimized development.
